# Diário de Saúde

Aplicativo **didático** para registrar hábitos diários e consultar o histórico.

> Este projeto existe exclusivamente para estudo. A prioridade é compreender o
> funcionamento e as decisões de um sistema full stack, não entregar
> funcionalidades rapidamente.

## Visão

Permitir que uma pessoa registre seus hábitos a cada dia e consulte o que
registrou. Possibilidades de evolução (não são um escopo fechado):

- Alimentação e bebidas
- Consumo de água e álcool
- Tabagismo
- Horas de sono
- Atividades físicas realizadas ou não
- Observações sobre o dia

Princípios:

- Cada usuário acessa **somente os próprios dados**.
- Durante o estudo, usamos **apenas dados fictícios**.
- É um diário de hábitos: **não produz diagnósticos nem recomendações médicas**.

## Objetivo didático

1. Entender como um projeto full stack funciona, do básico ao avançado:
   lógica e orientação a objetos, HTTP e JSON, integração frontend/backend,
   persistência com SQL e ORM, autenticação e autorização, validação,
   tratamento de erros, testes e fluxo de trabalho com Git.
2. Aprender a usar o **Claude Code** de forma consciente para analisar,
   planejar, implementar, testar e revisar software.
